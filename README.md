# 📖 British Vocabulary Dictionary

A comprehensive interactive British English vocabulary reference 
with 225+ entries, audio pronunciation, colour-coded cards, 
and smart search and filter functionality.

## 🌐 Live Demo
👉 [saraai2056-lang.github.io/british-vocabulary-dictionary](https://saraai2056-lang.github.io/british-vocabulary-dictionary)

## 💡 Why I Built This
As a serious learner of British English, I could not find a single 
resource that combined vocabulary from authentic British sources 
with audio pronunciation and smart filtering. So I built one.

## ✨ Features
- 225+ British English vocabulary entries
- Audio pronunciation via Google Translate TTS
- Colour-coded cards by source category
- Smart search and filter system
- Sources include The Crown, Peaky Blinders, Cunk on Earth, 
  Wicked Little Letters, and formal British English
- Single self-contained HTML file — no dependencies
- Fully mobile responsive

## 🛠️ Built With
- HTML5 / CSS3 / JavaScript
- Google Translate TTS API for audio
- GitHub Pages for deployment
- Built entirely on a mobile phone (Samsung Galaxy A36)
